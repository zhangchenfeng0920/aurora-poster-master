# Prompt 生成规则说明

对应实现：`scripts/prompt_rules.py`。本文件解释规则与为什么这么设计，便于维护。

## 1. Prompt 结构（v2.7.1 对齐：以 AI 总监 12 区块规范为唯一权威）

**最终出图指令的唯一权威模板是 SKILL.md「v2.7 AI总监 4A 高级版式提示词规范」的 12 区块结构**（11 固定 + 3 按需插入，按序拼接，互不重复）：

1. 【定位】——行业/子类目/受众/主题一句话锁定
2. 【创意概念】——Single-minded 单一诉求
3. 【主视觉与布景】——INDUSTRY_VISUAL + 主体清晰单一焦点
3-插.【人物设定】（仅出现人物时）——肖像权红线 + 多人五官不趋同
4. 【构图与视觉动线】——LAYOUT_MAP + 标题→卖点→CTA 强制动线
5. 【光影与质感】——LIGHTING_MAP + TEXTURE_MAP
6. 【色彩管理】——COLOR_MAP → ≤5 个 HEX → 可读性兜底
7. 【镜头语言】——CAMERA_MAP 景别景深
8. 【文字信息层级】——白名单制唯一文字来源（四重机制，见第 2 节）
8-补.【文字刻画】——FONT_MAP 字体气质 + TEXT_EFFECT 文字质感（描边/渐变金属/霓虹/书法/斜体）+ 竖排指定 + 关键数字放大与强调色（v2.8）
9. 【Logo预留】——AI 只留白不画 Logo（见第 4 节）
10. 【氛围情绪】——MOOD_MAP
10-插.【参考素材】（按需）——逐张携带用户主动描述
10-插.【补充要求】（按需）——用户其他需求逐条列入
11. 【负向提示词】——文字重复错乱/额外文字/Logo 水印/畸变/低质/遮挡
12. 【成片规范】——商业海报级、安全边距、4K、印刷屏幕双适配

**本文件其余各节是这 12 区块中「文字白名单」「Logo 边界」「行业视觉」「参数映射」的机制层解释，仍然有效**；凡本文与 SKILL.md v2.7 节表述不一致处，一律以 v2.7 为准。

> 历史说明：v2.1 及更早版本曾使用 7 区块（主题/视觉风格/文字气质/Logo区域/允许文字/严格要求/质量收尾）的程序化拼接结构，已被上述 12 区块完全取代，不再使用。

## 2. 文字去重规则（核心）

- 七个文字字段（主标题、副标题、营销金句、价格优惠、行动号召、联系信息、补充说明）只在第 5 区集中出现。
- 字段在进入列表前先做 `sanitize_text`：折叠所有空白为单空格并去除首尾空白，防止多行文字导致排版错乱。
- 使用 `seen` 集合：若不同字段填入了完全相同的字符串，只保留第一次出现的。
- 视觉风格区、主题区只描述风格，不复述用户的具体文字。

## 3. 严格要求区（固定指令）

生成时始终附加：

1. 列出的每段文字只出现一次，严禁任何形式重复；
2. 文字准确、清晰、完整，无错别字、不变形、不乱码；
3. 除列出的文字外，禁止任何其他文字、字母、网址、二维码、标签、符号；
4. 排版层级清晰、对齐规整、对比度足够、不被遮挡；
5. 所有按钮/框体/胶囊/徽章内的文字必须水平与垂直双向居中（v2.8 硬规则）；
6. 文字与背景高反差时直接压在背景上，禁止在文字下方加半透明色块、模糊遮罩或毛玻璃底衬（v2.8 红线）；
7. 不生成任何 Logo、品牌标志、水印。

## 4. Logo 处理边界

- 用户 Logo **绝不进入 prompt 的文字/绘图内容**，也不作为生图参考图。
- Prompt 仅在 `logo` 存在时，要求模型在 `logo_position`（左上角/顶部居中/右上角）预留干净安全区。
- Logo 的最终呈现完全由 `logo.py` 在本地用 Pillow 原样合成，保持透明度与原始比例。

## 5. 行业视觉提示词

每个一级行业对应一句可拍摄、可绘制的视觉描述（见 prompt_rules.INDUSTRY_VISUAL），
例如餐饮=热气腾腾的美食特写、金融=城市天际线抽象几何、医疗=洁净专业环境。
维护时只改这一个字典即可调整行业视觉基调。

## 6. 参数映射的单一数据来源

风格/色调/字体/排版/文字质感的中文取值到绘图关键词的映射集中在：
`STYLE_MAP / COLOR_MAP / FONT_MAP / LAYOUT_MAP / TEXT_EFFECT_MAP`（TEXT_EFFECT_MAP 为 v2.8 新增，见 design-params.md §5.5）。
新增一个可选风格时：在枚举文档 + 对应 map 中各加一条即可，调用方无需改动。

## 7. 设计禁忌（不要做）

- 不要在 prompt 中让模型"自由发挥加一些英文装饰字"。
- 不要把价格、电话等信息同时写进主题描述与文字列表。
- 不要在没有 Logo 时仍要求"预留 Logo 区"。
- 不要使用容易触发审核的绝对化、医疗功效承诺类词汇（文案模板已约束）。
