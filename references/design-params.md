# 设计参数枚举参考

所有参数在脚本中均有中文键名，用户可直接说中文；AI 推荐结果也使用这些取值。

## 1. 设计风格 style

| 取值 | 视觉含义（会映射为绘图关键词） |
|------|------------------------------|
| 简约 | 极简主义、大量留白、单一视觉焦点 |
| 极简 | 纯净背景、去装饰化 |
| 奢华 | 金色点缀、精致材质、影棚级布光 |
| 活泼 | 明快色彩、跳跃节奏、动感构图 |
| 国潮 | 新国潮、东方美学、传统纹样现代表达 |
| 科技 | 未来感、光影粒子、冷色金属 |
| 自然 | 柔和日光、真实材质、环保氛围 |
| 复古 | 胶片颗粒、年代配色、怀旧调性 |
| 商务 | 稳重布局、利落几何、专业感 |
| 可爱 | 圆润造型、柔和糖果色、治愈 |
| 梦幻 | 柔焦光晕、轻盈浪漫 |
| 高端 | 杂志感、高级灰、精致排版 |

| 圆润可爱 | 母婴、零食、儿童 |
| 书法国风 | 国潮、节庆、传统行业 |

| 纤细时尚 | 美妆、时尚、轻奢 |

## 5. 排版走向 layout_direction

| 取值 | 特征 |
|------|------|
| 居中对称 | 庄重稳定，节庆/官宣常用 |
| 左对齐 | 信息在左、主视觉在右（正文段落一律左对齐） |
| 右对齐 | 主视觉在左、信息在右 |
| 上下分割 | 上图下文 / 上文下图 |
| 对角线 | 动感、活力、促销 |
| 竖排点缀 | 短内容（店名/4~8字卖点）竖排从右往左，与横排主文案混排 |

## 5.5 文字质感 text_effect（v2.8 新增，逐项确认）

| 取值 | 效果 | 适用 |
|------|------|------|
| 纯色直排 | 单色无修饰 | 干净背景、信息小字（默认） |
| 描边字 | 白字深描边 / 深字白描边 | 文字压人物、纹理、光效 |
| 渐变金属 | 渐变填充 + 描边 + 投影 | 科技/工业/促销主标题 |
| 霓虹描边 | 发光描边撞色 | 娱乐/电玩/演出 |
| 书法 | 毛笔笔触 | 文化/国风/展览 |
| 斜体 | 主/副标题倾斜 8°~12° 增加个性 | 动感/促销/英文海报（仅标题可用，正文禁斜体） |

## 5.6 文字强调与居中规则（v2.8 新增）

- **数字放大**：价格/折扣/日期中的数字必须比同行文字大 1.5~2 倍，用画面唯一强调色；价格行=小字标签+超大数字混排。
- **居中硬规则**：所有框体/按钮/胶囊/徽章/色块内文字必须水平+垂直双向居中（以 textbbox 实测宽高反算坐标，禁止基线估算）；多行文字按整体行块居中。
- **对齐分工**：标题/按钮/徽章可居中；正文/须知/长文案一律左对齐。
- **禁遮罩红线**：文字与背景高反差时直接压背景，严禁半透明色块/模糊遮罩/毛玻璃底衬；可读性优先级：换字色 > 描边 > 投影 >（最后手段）≤15% 不透明度暗角。
- **字号阶梯**：主标题 : 副标题 : 卖点 : 联系方式 ≈ 1 : 0.55 : 0.4 : 0.3。

## 6. Logo 相关

- 支持格式：PNG / GIF（透明背景）
- 大小：≤ 500KB
- 建议尺寸：≤ 900×360
- 位置：左上角 / 顶部居中 / 右上角
- 合成约束（仅超限时触发等比缩小，不改样式）：
  - Logo 宽 ≤ 海报宽 25%
  - Logo 高 ≤ 海报高 15%
  - 距边缘边距 = 海报短边的 3%

## 默认推荐组合

- 不知道怎么选时：`风格=简约 / 色调=极光青绿 / 比例=9:16 / 字体=现代无衬线 / 排版=居中对称 / 质感=纯色直排`
- 餐饮促销：`活泼 / 暖橙红 / 9:16 / 圆润可爱或无衬线 / 居中对称 / 质感=描边字或斜体 + 数字放大撞色`
- 科技产品：`科技 / 极光青绿或霓虹紫 / 9:16 或 16:9 / 等宽科技 / 对角线 / 质感=渐变金属`
- 高端品牌：`高端 / 金色奢华 / 3:4 / 经典衬线 / 居中对称 / 质感=渐变金属或书法`
- 娱乐演出：`活泼 / 霓虹紫 / 9:16 / 现代无衬线 / 对角线 / 质感=霓虹描边 + 超大促销数字`
- 文化展览：`国潮或复古 / 大地色系或经典红金 / 3:4 / 书法国风 / 居中对称 / 质感=书法 + 竖排点缀`
